# История «Орбиты»

История восстановлена из 15 локальных архивов исходного кода. Каждая метка указывает на один сохранённый этап. Даты авторства взяты из времени изменения файлов архивов, а дата создания Git-коммитов соответствует дню импорта. Архивная подпись не указывает автора конкретной правки. Скриншоты добавлены к этапам, которые они иллюстрируют. В описаниях развёртывания адрес прежнего VPS и персональные почтовые реквизиты заменены примерами.
