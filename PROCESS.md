# Журнал создания

## 8 ноября 2026 — постановка задачи

Источник требований: пользователь передал конкурсное задание и уточнил, что нужен многопользовательский дневник, а два студента служат лишь примерами разделения данных.

Основные решения пользователя:

1. После входа открывается расписание текущего дня; отдельной главной страницы нет.
2. Референс IMG_2505.PNG: кликабельные дни с датами, недели, карточки с временем слева, типом пары, аудиторией, преподавателем, заметкой и окнами.
3. Пользователь разработает собственные темы; приложение должно поддерживать их переключение.
4. Раздел кружков: уполномоченные пользователи создают секции и расписание, видны сборные и соревнования.

Опрос студентов не проводился. Исследовательские интервью не выдумывались.

## Инструменты

- Codex: анализ требований, проектирование, генерация сервера, интерфейса, тестов и документации. Точное имя модели в журнале не утверждается.
- Sites skill: изучение доступного способа хостинга. Стандартный вход платформы связан с ChatGPT; для независимых университетских аккаунтов реализован отдельный переносимый Node.js-сервер. Sites не использован для публикации.
- PowerShell и Node.js 24: создание файлов, запуск сервера и тестов.
- SQLite через встроенный node:sqlite: хранение данных.
- Встроенный браузер Codex и инструмент управления браузером: вход, проверка 360 px, сохранение заметки, скриншот.
- Генераторы изображений, сторонние изображения, веб-шрифты, логотип университета и внешние ИИ API не использовались. Знак «Орбиты» построен CSS. Используются системные шрифты.

## Ключевые задания и результат

- «Не макет под двух пользователей, а полностью рабочая версия дневника» → пользователи и роли в базе; администратор создаёт дополнительные аккаунты.
- «Сверху кликабельные дни недели с датой, переключаться по неделям» → календарная лента с семью днями, стрелками и возвратом на сегодня.
- «Темы я разработаю ... менять темы» → CSS-переменные и сохранение выбранной темы на сервере.
- «Человек с выданными правами ... добавлять секции» → роль manager, проверка владельца секции, обработка заявок на вступление.
- «Главной пусть открывается расписание на сегодняшний день» → выбор текущей московской даты при входе.

## Проверка и ошибки

- Команда npm оказалась недоступна в окружении. Так как сторонних пакетов нет, запуск и тестирование выполнены напрямую через node.
- Интеграционный тест прошёл: проверены разделение данных, роли, заявки, секции, создание нового студента и защита запросов.
- В браузере подтверждены вход, отображение расписания на 360 px и сохранение личной заметки. Скриншот находится рядом с проектом: orbita-mobile.png.

## Ручные действия

Пользователь сформулировал требования, выбрал референс и уточнил разделы. Код, тесты и текущая тема написаны ассистентом. Авторские темы пользователя пока не переданы. Публикация, конкурсный PDF и видео пока не выполнены.

Этот журнал описывает только выполненное; не является окончательным конкурсным отчётом.
